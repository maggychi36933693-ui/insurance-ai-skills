五個步驟，把網站交給 Google

做完這五步，Google 就知道你的網站在哪裡、有哪些文章。框框裡的字點一下就會複製，回到 Claude 貼上送出。

0

先複製你的網站網址

打開你自己的網站，把網址列上整條網址複製起來，等一下會用到。

✓ 網址從 https:// 開頭，到 .pages.dev/ 結尾

1

登入 Search Console

打開 search.google.com/search-console，按「立即開始」，用自己的 Google 帳號登入。

看一下右上角的大頭貼，是不是你要用的帳號。瀏覽器裡同時登入公司和私人帳號的人，最容易登錯。

✓ 畫面跳出「選取資源類型」，左右兩個框

2

選右邊的框，貼上網址

選右邊「網址前置字元」，不要選左邊「網域」。

左邊的「網域」要改 DNS 設定，pages.dev 的網址做不到，選了會卡住。

在右邊的框貼上剛才複製的網址，按「繼續」。

✓ 畫面出現好幾種驗證方式

3

選「HTML 標記」，交給 Claude

  1. 點開「HTML 標記」，按「複製」。複製到的是一行 <meta name="google-site-verification" …>
  2. 先不要關掉 Search Console 這個分頁。
  3. 點下面的框複製這段話，回到 Claude 貼上，把【　】換成剛才複製的那一行，再送出：

這行標記以後也不要刪掉，刪了驗證會失效。

4

等 2 分鐘，再按「驗證」

Claude 說發布完成之後，等 2 分鐘再按。

網站更新要 1 到 2 分鐘。太早按，Google 還看不到標記，一定失敗。

回到 Search Console 的分頁，按「驗證」。

✓ 出現「已驗證擁有權」

失敗了？等 1 分鐘再按一次，大多就會過。還是不行，複製這段給 Claude：

5

提交網站地圖

  1. 按「前往資源」，在左邊選單找「Sitemap」。
  2. 「新增 Sitemap」的框裡，網址前半段已經自動帶好了。點下面的框複製，貼在後面，按「提交」。

提交後顯示「無法擷取」不用緊張，剛提交常常這樣，過幾天會變成「成功」。

＋

加分：請 Google 早點來

在 Search Console 最上面的搜尋框貼上你的首頁網址，按 Enter，再按「要求建立索引」。

寫了新文章也可以這樣做：把那篇文章的網址貼進去，按「要求建立索引」。

做完了，你已經把網站交給 Google

Google 收錄要幾天到幾週，不是今天就搜得到。

下週再搜一次自己的名字

例如「你的名字 高雄 保險」，看看網站出現了沒。

卡住了？

忘記 Google 帳號密碼

先跳過，回課堂做「標題改成客戶會搜的話」。回家找回密碼後，照這頁從第 1 步做。

不小心選到左邊「網域」

按左上角的資源名稱，選「新增資源」，重新選右邊「網址前置字元」就好。

以前好像有驗證過

左上角下拉看看有沒有你的網址。有的話直接做第 5 步。

還是不行

把畫面截圖貼給 Claude，問：「我卡在 Search Console 這裡，下一步怎麼辦？」或截圖貼到課程群組。

Search Console 是 Google 官方的免費工具，只是讓 Google 知道你的網站，不會改動你的網站內容。
