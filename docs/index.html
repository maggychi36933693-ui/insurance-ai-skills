AI 技能包・安裝頁

三個步驟，裝好 18 個 AI 技能

給保險業務員用的 Claude Code 技能：品牌、網站、Google 搜尋、IG 社群。全部繁體中文，合規檢查內建。

1

打開 Claude 桌面版，切到「Code」分頁

在電腦上做，手機不行。

2

選你的網站資料夾

通常在桌面，叫「我的網站-你的名字」。技能會裝在這個資料夾裡。

3

按下面的按鈕，貼到對話框送出

複製好之後，回到 Claude 的對話框，按 ⌘ Command ＋ V 貼上，再按送出。（Windows 是 Ctrl ＋ V）

https://github.com/maggychi36933693-ui/insurance-ai-skills

請把這包 Skill 安裝到我目前開啟的資料夾：把 skills 裡的每個資料夾放進這個資料夾的 .claude/skills/。裝完列出裝了哪些，並確認可以使用。

看到它列出 18 個技能，就裝好了

開一個新對話，說這句開始：

「開始用社群技能」

它會先帶你填好語氣檔，並建好「社群」資料夾。

卡住了？

跳出視窗問「要不要允許執行」

按「允許」。它要從 GitHub 下載技能包，這是正常的。

裝好了，但說「開始用社群技能」沒反應

開一個新對話再試一次，或關掉資料夾重新開啟。新裝的技能有時要重新開始才會出現。

在資料夾裡找不到 .claude

它是隱藏資料夾。Mac 的 Finder 按 ⌘ Command ＋ Shift ＋ . 就看得到。不用去找也沒關係，Claude 看得到就好。

按鈕按了沒反應

直接選取上面深色框裡的整段文字，複製貼上也一樣。

還是不行

把畫面截圖貼給 Claude，問：「我卡在這裡，下一步怎麼辦？」或截圖貼到課程群組。

這些技能只寫草稿，不會幫你發文，也不會登入你的任何帳號。社群貼文和網站文章都算對外文宣，發布前請送公司法遵或主管審核。
